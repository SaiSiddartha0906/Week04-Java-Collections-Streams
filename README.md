## 🧭 Overview
This week was all about harnessing the power of Java Collections and the Stream API for modern data manipulation. We learned how to transform and filter data in a more expressive and concise way using streams, lambda expressions, and built-in functional interfaces.

## 📌 Topics Covered

### Day 1: Review of Collections – List, Set, and Map
- Revisiting `ArrayList`, `HashSet`, and `HashMap`
- Sorting collections using `Collections.sort()` and `Comparator`
- Iterating with forEach, Iterator, and enhanced for loop

### Day 2: Introduction to Java 8 Streams
- What is a Stream?
- Stream creation from collections and arrays
- Advantages of using streams
- Internal vs external iteration

### Day 3: Intermediate Stream Operations
- `filter()`, `map()`, and `flatMap()`
- `sorted()` and custom sorting
- Chaining multiple stream operations

### Day 4: Terminal Stream Operations
- `forEach()`, `collect()`, `toList()`
- `count()`, `min()`, `max()`, `anyMatch()`, `allMatch()`, `noneMatch()`
- Finding elements with `findFirst()` and `findAny()`

### Day 5: Collectors, Grouping, and Partitioning
- Using `Collectors.toList()`, `toSet()`, `toMap()`
- Grouping data with `Collectors.groupingBy()`
- Partitioning data with `Collectors.partitioningBy()`
- Summarizing and reducing values

### Day 6: Optional, Lambda Expressions, and Functional Interfaces
- Introduction to `Optional` and avoiding null checks
- Writing concise code using lambda expressions
- Built-in functional interfaces: `Predicate`, `Function`, `Consumer`, `Supplier`
- Custom functional interfaces and method references

## 🛠️ Prerequisites
- Solid understanding of core Java and OOP concepts
- Familiarity with Java Collections (Week 3)
- Java 8 or higher installed

## 📂 How to Use This Repository
Each day of learning is organized into a separate folder. Inside each, you will find code samples and practice exercises. Open the files in your IDE, run the code, and experiment with it to solidify your understanding of functional-style Java.
